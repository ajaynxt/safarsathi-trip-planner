# Safar Sathi — Trip Planner

A responsive, mobile-friendly itinerary planner for Safar Sathi.

## Features
- Create and edit trips with destination, dates, travellers, budget and travel style.
- Add day-wise activities with time, category, location and estimated cost.
- Track estimated expenses against the trip budget.
- Share a read-only trip link.
- Export an itinerary through browser Print → Save as PDF.
- Responsive layout and Safar Sathi WhatsApp enquiry link.

## Run locally
Open `index.html` in a browser. No build step or paid service is required.

## Deploy with GitHub Pages
Open **Settings → Pages**, choose **GitHub Actions** as the build source, and save. The included workflow publishes the site when changes are pushed to `main`.

## Data and privacy
Trips are saved in this browser's local storage. Share links include trip details in the URL fragment; anyone with the link can view the trip. Do not include sensitive information. This starter version has no central database and does not sync trips across devices. A Firebase backend can be added later for secure accounts and cloud sync.
